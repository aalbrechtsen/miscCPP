# miscCPP

Small C/C++ programs for population genetics and sequencing data. Each one is in its own folder, with a README that explains how to build and use it.

| Program | What it does |
|---|---|
| [BAMSE](bamse/README.md) | Bayesian association mapping with multiple SNPs and environmental factors. An MCMC method that finds sets of SNPs and environmental factors that together change disease risk or a quantitative trait, including interactions. |
| [refFinder](refFinder/README.md) | Extracts bases from an indexed fasta file, either as a stand-alone program (positions piped in) or through a small C API. |

Both programs used to be on the popgen.dk software wiki.
